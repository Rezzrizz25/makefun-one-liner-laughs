A make.fun entry for the **One-Liner Laughs** bounty: write a single funny line, 200 characters at most.

## The entry

> I asked the AI to roast me; it said, 'I'd love to, but your search history already did.'

(88 characters. You dare the AI to roast you; it declines — and the refusal is the roast, because your search history already did the job.)

## Run

```sh
node main.ts
```

This writes the single line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), with in-code gate checks: single line, non-blank, 1–200 characters, plus a read-back verification that the file on disk is byte-identical to the entry. The program prints exactly the one line to stdout and nothing else.
